# Technical Typing Practice — Project Summary

## Idea

Most typing websites train speed on random words or quotes. This project is a **technical typing trainer**: users type real code, commands and technical text, and see **what each part does while they type**. They practice typing and learn the content at the same time.

### Why it matters now

AI agents write most of the code today, so the pitch is not "type code faster". It is **"learn to read and recognize code by typing it"**. People still need to review, understand and fix what agents produce, and still type terminal commands, SQL, git, config files and prompts.

## Core Features

1. **Typing practice** — standard typing engine (WPM, accuracy) with extra tracking for symbols common in code: `{ } [ ] ( ) _ -> ::`.
2. **Choose language / OS / category** — a tree: Category → Topic → Lessons.
   - Languages and tools: Python, PHP, Microsoft (PowerShell, Excel formulas), Terminal, Git, SQL
   - Groups: Computer Science, Data Analysis, and others
3. **Live "what is it doing" panel** — as the cursor reaches each chunk of code, a side panel shows a short explanation (for example `for row in rows:` → "Loop: repeat for every row in the list"). This is the main differentiator.

## Key Decision: No Runtime AI

- All content (snippets and explanations) is **generated by AI in advance**, reviewed by a human, then **fixed as static data**.
- No AI API calls at runtime, no backend needed, no per-user cost, no live wrong answers.
- Works as a static site (Vercel / Netlify / GitHub Pages), could work offline.

## Lesson Data Format (JSON)

```json
{
  "id": "python-loop-01",
  "category": "Data Analysis",
  "topic": "Python basics",
  "level": 1,
  "tags": ["loop", "print"],
  "chunks": [
    { "code": "for row in rows:", "explain": "Loop: repeat for every row in the list" },
    { "code": "    print(row)", "explain": "Show the current row on screen" }
  ]
}
```

The typing engine only needs to know which chunk the cursor is in and display that chunk's `explain` text. New content = new files, no code change.

## Content Pipeline

1. Define the category and topic list by hand.
2. Ask AI to generate snippets in the exact JSON format above (short: 3–10 lines each).
3. Run a validation script: valid JSON, no empty explanations, and code actually runs where possible (Python, shell).
4. Human review of explanations (optionally a second AI pass), fix errors, then freeze the files.

Biggest risk: wrong explanations or broken code. Quality over quantity.

## MVP Scope (first version)

- One web page, no accounts, no backend.
- 2 tracks: **Python basics** and **Terminal / Git**.
- About 20 high-quality snippets total, each with chunk explanations.
- Layout: typing area on the left, explanation panel on the right.
- Result screen: WPM, accuracy, and the symbols/keys missed most.

## Ideas for Later

- **Hints on/off mode**: first pass with explanations, later pass hidden so users must recall what each line does.
- **Short quiz after a snippet** ("what did line 2 do?").
- **Progress by concept**, not only WPM (for example weak at loops, strong at filtering) — done by picking existing lessons by tag, still no AI.
- **Prompt-writing lane**: practice typing good prompts and instructions for AI agents.
- More categories and levels once users return.

## Limits to Accept

- No personalized or generated lessons; only selection from existing ones by tag.
- Content grows only when added manually.

## Open Questions

1. Target user first: beginners learning to code, or working people (for example data analysts) who need to understand what agents produce?
